Responsive Design Test - Resume Website

This page tests the responsive behavior at different breakpoints.

Mobile Layout (< 768px)

Testing at 375px width (typical mobile)

✓ Navigation should be compact with smaller text

✓ Profile image should be 150px

✓ Contact links should stack vertically

✓ All sections should have reduced padding

Tablet Layout (768px - 1023px)

Testing at 768px width (typical tablet)

✓ Navigation should have medium spacing

✓ Profile image should be 180px

✓ Contact links should be horizontal

✓ Sections should have medium padding

Desktop Layout (≥ 1024px)

Testing at 1024px width (typical desktop)

✓ Navigation should have full spacing

✓ Profile image should be 200px

✓ Contact links should be horizontal with large gaps

✓ Sections should have maximum padding

✓ Content should be centered with max-width

Manual Testing Instructions

  1. Open index.html in a browser
  2. Open browser DevTools (F12)
  3. Toggle device toolbar (Ctrl+Shift+M or Cmd+Shift+M)
  4. Test at these widths:
    • 375px (Mobile)
    • 768px (Tablet)
    • 1024px (Desktop)
  5. Verify:
    • Navigation is accessible and readable at all sizes
    • Text remains readable
    • Images scale appropriately
    • Layout adapts smoothly
    • No horizontal scrolling on mobile
